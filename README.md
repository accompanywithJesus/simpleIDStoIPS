# Python Log Attack Detector

## Oveview
This project is a simple Python_based log analyzer that detects suspicious URL patterns from Web Server Logs

##Features
- Extract IP address,time,and URL from log lines
- Detect suspicious patterns such as admin,scrpt,union,alert and../
- Print alerts for detected attack attemps
- Save suspicious IPs to a blacklist file

##What I Learned
- String slicing
- split() function
- Pythpnb functions
- Dictionary-based pattern matching
- Basic log analysis
- Simple IDS logic
